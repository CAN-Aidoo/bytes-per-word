# CANLABS research project

This repository is run by the `canlabs-research-os` plugin. Rules (enforced by hooks where possible):
- Read `.lab/STATE.md`, `.lab/TASKS.md`, `.lab/ALERTS.md` before working. Write only files you own (`.lab/OWNERS.md`).
- Gates G0-G4 are approved only by the human with `/lab-gate`. Never edit `.lab/gates.json`.
- `PROTOCOL.md` is append-only after G1. `heldout/` stays closed until G2.
- No invented data, results or citations. Every number in the paper comes from `paper/numbers.tex`, generated by `analysis/`.
- Report problems in `.lab/ALERTS.md` as `RED|AMBER <date> <agent> <issue> <file:line>`. A RED alert stops the pipeline.
- Reproduce everything with `make all`.
